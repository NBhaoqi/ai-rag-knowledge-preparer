# RAG 知识库资料准备器

**GitHub 项目简介：** 为 RAG 知识库整理源资料、切分策略、元数据和可追溯的检索材料。

本项目提供一个可复用的 Agent Skill，帮助准备进入检索增强生成（RAG）流程的资料。它强调保留原文语义、定位来源、记录文档版本，并明确解析或 OCR 的不确定性。

## 功能

- 根据检索问题和源文件类型设计资料清点与预处理方案。
- 保留标题层级、段落、列表、表格上下文和原始位置线索。
- 为文档或片段规划一致的元数据与来源标识。
- 识别重复、版本冲突、缺页、解析错误和可能的敏感信息。
- 设计可检查的抽样验证，避免把“已整理资料”误报为“已完成索引或检索评估”。

## 安装

将 `skills/ai-rag-knowledge-preparer` 目录复制到支持 Agent Skills 的宿主所配置的技能目录中，然后按宿主说明启用或刷新技能。具体安装位置和调用方式以宿主文档为准。

## 使用示例

```text
我准备把产品手册和客服 FAQ 用于 RAG 检索。
请先检查文件类型与结构，建议切分和元数据方案，并列出需要人工确认的版本冲突。
保留每段内容的文件名和原文位置，不要声称已经建立向量索引。
```

也可以指定目标检索系统的片段长度、元数据字段、语言、访问权限或输出格式；未提供的系统限制应列为待确认项。

## 适用边界

此技能用于资料盘点、预处理和索引准备方案，不保证特定检索框架、嵌入模型或向量数据库的效果。只有实际调用相应工具并检查结果后，才能声称文件解析、OCR、索引写入或检索评估已经完成。处理受限或敏感资料时，应遵守来源授权、访问控制和数据最小化要求。
